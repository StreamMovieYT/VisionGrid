2. Welche Daten verarbeitet VisionGrid?

VisionGrid speichert vom Nutzer eingegebene Daten lokal auf dem Gerät. Dazu können gehören:

  • Artikelname, Beschreibung, Notizen und Suchbegriffe
  • Bestand, Zielbestand und Warnwerte
  • Regalnamen, Fachpositionen und Marker-IDs
  • optional ausgewählte Artikelbilder

3. Kamera

Die Kamera wird verwendet, um Marker zu erkennen. Kamerabilder werden nicht an einen Server übertragen. Die Verarbeitung erfolgt lokal auf dem Gerät.

4. Speicherung

5. Weitergabe an Dritte
