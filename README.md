# VisionGrid Play-Store-Webseite

Diese kleine statische Webseite enthält:

- Startseite für VisionGrid
- Datenschutzerklärung für Google Play
- Kontaktbereich

## Vor Veröffentlichung ersetzen

In `index.html` bitte ersetzen:

- `DEINE-KONTAKT-EMAIL@example.com`

Empfohlen:

- Eine separate Support-Mail, z. B. `visiongrid.app@gmail.com`
- Nicht unbedingt deine private Haupt-Mail verwenden.

## Veröffentlichung

Geeignete kostenlose Optionen:

- GitHub Pages
- Google Sites
- Netlify
- Vercel

Für Google Play brauchst du danach die öffentliche URL zur Datenschutzerklärung, z. B.:

`https://deinname.github.io/visiongrid/#privacy`

oder besser:

`https://deine-domain.de/visiongrid/#privacy`

## Danach in Google Play Console eintragen

- Store listing → Privacy Policy URL
- App content → Data safety
- Developer contact email
- App support email
